# Cycling-Memory
## About the Project
For the CCH Rapid Development Challenge #3, Marinna and Steven created a map visualizing the growing popularity of bicycle-related events in the United States throughout a seventy year span. The map includes the location of inaugural rides, most of which continue to be held to this day on an annual basis. A variety of races are represented, like gravel and road races, and competitive and noncompetitive races.
## Repository Structure
The repository contains the following files and directories: 
- **assets/** - Contains supporting files. 
- **css/** - Contains stylesheets that control website's visual appearance. 
- **CyclingMemory_IMGs** - Contains images for each ride. 
- **js** - Contains JavaScript files that support website's functionality. 
- **About.html** - Contains the HTML code for the project's About Page. 
- **BikeIcon.png** - An image used for our map marker. 
- **index.html** - The main HTML file for our project.
